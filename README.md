# Enter BIOS shortcut

Do you always spam your keyboard with the correct key just to boot into BIOS? Well, we can simply create a simple desktop shortcut that allows us to save time and without being a madman pressing those key/s.

<h2>Steps</h2>
<ol>
  <li>Right-click into your desktop
    <br>
      <img src="https://github.com/user-attachments/assets/aac8ed30-e1ca-4197-9cc6-7f9921e1b372" style="width:50%"/>
  <li> Select New, then Shortcut
    <br>
      <img width="615" height="519" alt="image" src="https://github.com/user-attachments/assets/c99dbf1d-3625-4d94-9797-ec440c39161f" style="width:50%"/>
  <li>Paste the following command:
    <pre><code>shutdown /r /fw /t 00</code></pre>
      <br>  
        <img src="https://github.com/user-attachments/assets/cfa556c9-2f5c-4423-bc1b-c1dbaaa06175" style="width:50%"/>
  </li>
  <li>Name it as:
    <pre><code>Go to BIOS</code></pre>
      <br>
        <img src="https://github.com/user-attachments/assets/0dd34170-1ed9-413d-8f48-ce963fb3f940" style="width:50%"/>
  </li>
  You could name it however you want
  <li>Right-click shortcut, then go to Properties
    <br>
      <img src="https://github.com/user-attachments/assets/62f9e480-532b-42c1-96ec-fac3368063cf" style="width:50%"/>
  </li>
  <li>Click Advanced, under Shortcut tab
    <br>
      <img src="https://github.com/user-attachments/assets/ebec996d-80b7-4167-9798-017cd1553543" style="width:50%"/>
  </li>
  <li>Check Run as administrator, then click OK and Apply
    <br>
      <img src="https://github.com/user-attachments/assets/7c532d36-8f0f-4519-8363-16f44f25567c" style="width:50%"/>
  </li>
  <li>Now double-click it then you'll be able to boot straight to the BIOS
  </li>
</ol>
